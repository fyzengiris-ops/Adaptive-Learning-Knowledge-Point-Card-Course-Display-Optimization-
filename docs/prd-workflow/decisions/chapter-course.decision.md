## 已确认决策
1. 标题：顶栏「课程中心-章节名」
   - 决策：A
   - 结论：章节名来自进入课程中心时选中的章节；格式固定为「课程中心-」+ 章节完整名称（与首页目录文案一致）
   - 影响范围：页面显示、入口带入数据

2. Tab：课型（同步/专题/拓展）
   - 决策：A
   - 结论：切换课型时，左侧课程、右侧试卷、课程/试卷辅助文案与数量全部切换为该课型数据；校本课仍不在本期
   - 影响范围：课型切换、左右联动、文案与统计

3. 按钮：筛选入口
   - 决策：A
   - 结论：章节页任意课型下均可打开筛选；筛选作用于当前页可见的课程区与试卷区（不含校本课）
   - 影响范围：筛选入口可用性、作用域

4. 筛选：抽屉选项结构
   - 决策：A（试卷状态选项以第 14 条扩展）
   - 结论：抽屉内两组——课程状态（待学习/学习中/已学习）三选一 + 试卷状态（未练习/练习中/已练习）三选一；两组都展示并可同时生效；课程条件只滤课程，试卷条件只滤试卷
   - 影响范围：筛选抽屉字段结构、过滤规则

5. 按钮：筛选「确定」
   - 决策：自定义方案
   - 结论：点确定后立即按当前条件过滤并关闭抽屉；课程区无匹配时显示「当前筛选状态暂无课程，可调整筛选项」；试卷区无匹配时显示「当前筛选状态暂无试卷，可调整筛选项」
   - 影响范围：筛选生效、分区空结果文案

6. 按钮：筛选「取消」
   - 决策：A
   - 结论：取消/关闭/点遮罩只关抽屉，不改变已生效筛选；另需提供「清除筛选」才能恢复未筛选
   - 影响范围：筛选恢复、抽屉关闭行为

7. 文案：课程辅助文案
   - 决策：A
   - 结论：三套定稿文案按课型固定展示——同步「教材同步 · 循序渐进」、专题「重难点 · 专项突破」、拓展「学有余力 · 拔高拓展」；不随筛选变化
   - 影响范围：页面显示、课型切换文案

8. 统计：课程数量（X 门）
   - 决策：A
   - 结论：显示当前课型下课程总数；筛选后改为筛选后可见数量；为 0 时仍显示「0 门」
   - 影响范围：统计口径、筛选联动

9. 区域：课程列表/卡片区
   - 决策：A
   - 结论：课程归属「当前章节 + 当前课型」；无课程时左侧显示「当前类型暂无资源，可查看其他类型的资源」
   - 影响范围：数据归属、课程空状态文案

10. 状态：课程学习状态
    - 决策：A
    - 结论：三态为「待学习 / 学习中 / 已学习」，筛选选项与之一一映射
    - 影响范围：状态展示、课程筛选项
    - 评审补充（2026-08-11）：
      - 【8.11需求评审后补充】所有视频待学习：指从未打开过这个视频；学习中：指打开过这个视频，但是这个视频还未看到最后；已学习：指打开过这个视频，且已看到视频最后（无论是自然看到最后，还是手动拖动到最后，都算是已学习）。
    - 影响范围：状态展示、课程筛选

11. 文案：试卷辅助文案
    - 决策：A
    - 结论：三套定稿按课型固定展示——同步「及时巩固」、专题「强化突破」、拓展「挑战进阶」；不随筛选变化
    - 影响范围：页面显示、课型切换文案

12. 统计：试卷数量（X 套）
    - 决策：自定义方案
    - 结论：显示当前课型试卷总数；筛选后显示可见数量；筛选后为 0 时显示「0 套」；若该课型本身为空配置（未配置试卷），则隐藏数量
    - 影响范围：统计口径、空配置与筛选零结果区分

13. 区域：试卷列表归属
    - 决策：A
    - 结论：试卷归属「当前章节 + 当前课型」；切换课型只看该课型配套试卷
    - 影响范围：数据归属、课型切换

14. 状态：试卷练习状态
    - 决策：B
    - 结论：试卷状态为「未练习 / 练习中 / 已练习」三态；筛选试卷状态分组同步为这三项（三选一），与列表状态一一映射
    - 影响范围：状态展示、试卷筛选选项

15. 文案：试卷元信息（题数/时长/得分）
    - 决策：自定义方案
    - 结论：未练习、练习中显示题数 + 预计时长；已练习显示题数 + 得分；字段由配置/作答结果提供，不缺省
    - 影响范围：列表字段展示、状态差异

16. 按钮：试卷操作（去练习/查看详情）
    - 决策：自定义方案
    - 结论：未练习进入该卷练习作答页；已练习进入该卷详情页；练习中进入该卷作答页，并定位到需作答的第一题；返回后仍停留在章节页当前课型与筛选条件
    - 影响范围：跳转目标、返回态恢复

16b. 流转：练习试卷完成后的去向
    - 决策：评审补充
    - 结论：【8.11需求评审后补充】只要这份练习试卷完成练习了（用户已提交整份试卷-系统已全部自动批改/或待学生自批），这份试卷就会流转到首页的「练习记录」模块的试卷 tab 栏目下，同时练习试卷里练习过的题目，也都会流转到首页的「练习记录」模块的题目 tab 栏目下。
    - 影响范围：练习完成态、首页练习记录试卷/题目 tab

17. 空状态：试卷空状态
    - 决策：A
    - 结论：任一课型无试卷时，用「暂未配置{课型名}练习试卷」+ 说明「可以先去练习其他课型的配套试卷，巩固所学内容」
    - 影响范围：空配置文案（区别于筛选无匹配文案）

18. 按钮：空状态跳转（去同步课试卷/去专题课试卷）
    - 决策：A
    - 结论：点击后切换到对应课型 Tab，并联动左右课程与试卷；若目标课型也无试卷，继续显示该课型空状态
    - 影响范围：空态引导、课型跳转

19. 滚动：课程列表过多时
    - 决策：A
    - 结论：课程与试卷均在各自区域内滚动；首屏条数由 UI 定；不分页
    - 影响范围：列表浏览、不做分页
