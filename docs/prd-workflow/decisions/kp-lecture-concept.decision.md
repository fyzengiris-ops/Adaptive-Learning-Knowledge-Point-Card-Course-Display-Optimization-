## 已确认决策
1. 字段：学业要求
   - 决策：修订（相对原 A）
   - 结论：非必配；已配置时学生端以印章短文案展示；未配置时不展示印章。枚举为封闭集合「了解 / 理解 / 掌握 / 运用」（可按现网微调但仍为封闭枚举）。具体展示标签由配置后台下发/获取，学生端按后台返回值展示。
   - 影响范围：页面显示、数据来源、空状态

2. 字段：考察频率
   - 决策：修订（相对原 A）
   - 结论：非必配；已配置时学生端以印章展示；未配置时不展示印章。后台封闭枚举「高频 / 中频 / 低频」。具体展示标签由配置后台下发/获取，学生端按后台返回值展示。
   - 影响范围：页面显示、数据来源、空状态

3. 文案：核心概念页签
   - 决策：A
   - 结论：固定文案「核心概念」，后台不可配、学生端不可改。
   - 影响范围：页面显示

4. 区域：要点模块
   - 决策：B
   - 结论：允许 0 条要点；无要点时整块「要点」模块不渲染，不展示空容器。
   - 影响范围：页面显示、空状态

5. 文案：单条要点正文
   - 决策：自定义方案
   - 结论：本页不提供富文本编辑能力；学生端需支持渲染乐课网现有富文本编辑能力所能产出的展示效果（按乐课网富文本能力集展示，不在本页编辑）。
   - 影响范围：页面显示、数据边界

6. 区域：要点配图
   - 决策：自定义方案
   - 结论：允许单条要点展示多张图片；多图呈现效果与后台配置一致，支持换行多图或单行多图；无图不占位；点击放大等交互按学生端图片预览能力处理，并与配置侧展示形态对齐。
   - 影响范围：页面显示、操作

7. 区域：公式定理模块
   - 决策：A
   - 结论：未配置公式时整块不展示；已配置则全部按后台顺序展示；每条按「名称：内容」单行呈现（名称可空，空则只展示内容）。模块左上角标签：仅 1 条时为「公式定理」，多条时为「公式定理 · N 条」。
   - 影响范围：页面显示、空状态、数据边界

8. 操作：左右滑切换到考点
   - 决策：C
   - 结论：仅支持底部分页圆点与底栏箭头切换进入考点清单页；不支持手势左右滑，避免与页内纵向滚动冲突。
   - 影响范围：操作、页面流转

9. Tab：知识点视频
   - 决策：自定义方案
   - 结论：配置后台已配置该知识点视频信息时展示「知识点视频」Tab；未配置视频时不展示该 Tab。仅配置了视频、未配置知识点精讲时，「知识点精讲」Tab/模块暂不展示，仅展示视频相关内容。有精讲可进入时默认落在「知识点精讲」。若视频与知识点精讲均未配置，用户点击「知识点学习」不进入精讲页，弹窗提示「正在更新中，先去学习其他知识点吧~」。
   - 影响范围：页面显示、空状态、异常边界、页面流转
