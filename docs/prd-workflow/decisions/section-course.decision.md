## 已确认决策
1. 范围：校本课
   - 决策：自定义方案
   - 结论：校本课不属于本期范围，本次不审核、不实现校本课相关逻辑
   - 影响范围：页面范围边界、后续注册表 `excludedDecisions`

2. 区域：同步课三类来源与备课资料类型区分
   - 决策：B（并明确本期重点）
   - 结论：三类来源区分已具备；本期重点做好类型区分展示。任课教师备课资料在来源内再按文件类型分子类展示（如视频 / PPT 等）
   - 影响范围：页面显示、资源归类、备课资料列表结构
   - 评审补充（2026-08-11）：
     - 【8.11需求评审后补充】PPT 达到已学习的行为为看到最后一页，即状态变更为已学习。

3. 字段：来源 Tab 数量角标
   - 决策：C
   - 结论：角标显示「当前筛选后可见数量」；无筛选时等于全部数量；数量为 0 时 Tab 仍显示
   - 影响范围：页面显示、筛选联动、空数据角标表现

4. 状态：课程学习状态与筛选项
   - 决策：自定义方案
   - 结论：课程状态保留「待学习 / 学习中 / 已学习」三态；筛选对应改为这三项，一一映射。
   - 影响范围：筛选选项、课程状态过滤规则
   - 评审补充（2026-08-11）：
     - 【8.11需求评审后补充】已学完的逻辑和目前已经实现的逻辑保持不变。
     - 【8.11需求评审后补充】每个视频资源，在学习的时候，都需要记录用户单次浏览视频的累计时长，是否达到视频总时长的50%，如果满足，则将该视频进行计数，以便后续学习报告统计数据使用，同时一个视频，单日最多只计数1次。

5. 区域：练习试卷归属
   - 决策：A
   - 结论：练习试卷只挂在「当前小节 + 同步课」下，与左侧来源无关；切换来源 Tab 时，右侧试卷列表不变
   - 影响范围：数据归属、来源切换、右侧试卷展示

6. 空状态：无课程 / 无试卷
   - 决策：自定义方案（分区空状态 + 引导）
   - 结论：无课程提示「当前类型暂无资源，可查看其他类型的资源」；无试卷提示「暂未配置试卷」
   - 影响范围：空状态文案、分区提示

7. 列表：数据过多
   - 决策：A
   - 结论：课程与试卷都支持区域内滚动；首屏展示数量由 UI 确定；超出继续滚动，不分页
   - 影响范围：列表滚动、不做分页

8. 筛选抽屉：选项结构
   - 决策：A
   - 结论：同一抽屉内分两组：课程状态（待学习 / 学习中 / 已学习）三选一 + 试卷状态（待练习 / 练习中 / 已练习）三选一，两组都展示
   - 评审补充（2026-08-11）：试卷筛选补齐「练习中」维度，由原「已练习 / 待练习」二选一调整为三选一。
   - 影响范围：筛选抽屉字段结构

9. 筛选抽屉：多条件是否同时生效
   - 决策：A
   - 结论：可同时生效；课程条件只滤课程，试卷条件只滤试卷
   - 影响范围：筛选生效规则、左右区域联动

10. 筛选结果：无匹配时的展示
    - 决策：自定义方案
    - 结论：哪个区域无匹配，就在哪个区域显示「暂无资源」
    - 影响范围：筛选空结果提示文案

11. 筛选抽屉：取消与清除
    - 决策：A
    - 结论：取消 / 点遮罩 / 点关闭只关闭抽屉，不改变已生效筛选；另提供「清除筛选」才能恢复未筛选
    - 影响范围：筛选恢复、抽屉关闭行为

12. 流转：练习试卷完成后的去向
    - 决策：评审补充
    - 结论：【8.11需求评审后补充】只要这份练习试卷完成练习了（用户已提交整份试卷-系统已全部自动批改/或待学生自批），这份试卷就会流转到首页的「练习记录」模块的试卷 tab 栏目下，同时练习试卷里练习过的题目，也都会流转到首页的「练习记录」模块的题目 tab 栏目下。
    - 影响范围：练习完成态、首页练习记录试卷/题目 tab
