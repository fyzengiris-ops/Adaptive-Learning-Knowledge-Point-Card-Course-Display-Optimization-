## 必审对象
1. 顶栏标题「课程中心-章节名」 — 标题 — 顶栏居中 — 定当前章节数据范围与展示格式
2. 课型 Tab（专题/拓展） — Tab — Tab 栏 — 切换后左右课程与试卷如何联动
3. 筛选入口 — 按钮 — 顶栏右侧 — 打开筛选抽屉
4. 筛选抽屉（学习状态选项） — 筛选 — 抽屉 — 课程三态 + 试卷已练习/待练习口径
5. 筛选「确定」按钮 — 按钮 — 抽屉底部 — 确认筛选并生效
6. 筛选「取消」按钮 — 按钮 — 抽屉底部 — 关闭/不生效规则
7. 课程辅助文案 — 文案 — 课程标题旁 — 两套短文案随课型切换
8. 课程数量（X 门） — 统计 — 课程辅助文案后 — 计数口径、筛选后是否变化
9. 课程列表/卡片区 — 区域 — 左侧内容 — 列表数据范围、空/多数据
10. 课程学习状态 — 状态 — 课程卡片 — 待学习/学习中/已学习
11. 试卷辅助文案 — 文案 — 试卷标题旁 — 两套四字文案随课型切换
12. 试卷数量（X 套） — 统计 — 试卷辅助文案后 — 计数口径、空态时是否隐藏
13. 试卷列表区 — 区域 — 右侧内容 — 归属当前课型、数据来源
14. 试卷练习状态 — 状态 — 试卷条目 — 未练习/已练习
15. 试卷元信息（题数/时长/得分） — 文案 — 试卷条目 — 未练与已练展示字段差异
16. 试卷操作（去练习/查看详情） — 按钮 — 试卷条目右侧 — 随状态切换的操作结果
17. 试卷空状态 — 空状态 — 拓展课右侧 — 文案与引导跳转
18. 空状态跳转（去专题课试卷） — 按钮 — 空状态区 — 跳转后 Tab 与内容如何切换
19. 课程列表滚动（过多时） — 滚动 — 左侧列表 — 是否约定滚动/无分页
