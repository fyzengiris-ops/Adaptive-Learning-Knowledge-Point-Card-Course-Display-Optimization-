## 必审对象
1. 学业要求 — 字段/状态 — 标题旁印章文案 — 后台可选值与学生端展示规则
2. 考察频率 — 字段/状态 — 标题旁印章文案 — 后台可选值与学生端展示规则
3. 核心概念页签 — 文案/分页标识 — 「01 核心概念」居中页签 — 固定文案，Skill1/注册表按固定展示落结论
4. 要点模块 — 区域 — 「要点」容器内多条编号要点 — 后台配置条数、顺序、空态；学生端呈现
5. 单条要点正文 — 文案 — 要点列表每一条 — 富文本/换行等配置边界与学生端展示
6. 要点配图 — 区域/媒体 — 要点下大图（可点击放大） — 有图无图、挂靠哪条要点、放大规则
7. 公式定理模块 — 区域 — 要点下方「公式定理」块 — 有则显示无则隐藏；多条「名称：内容」规则
8. 左右滑切换到考点 — 操作 — 卡片左右滑 / 底部分页 — 本页审：如何进入考点清单页

## 可跳过对象
1. 知识点名称 — 进页则名称必存在，不出现缺省
2. 进入考点页的引导文案 — 注册表按固定信息展示描述即可，本期不深审分支
3. 顶栏演示多考点/单考点开关 — 仅评审演示，非正式学生能力
4. 知识点视频 Tab — 占位未接入，非核心概念内容
5. 返回 / 查看笔记 / 去测试 — 壳层入口，本期不审
6. 考点清单及相关对象 — 后续单独 Skill0

## 供 Skill1 使用的约束
- 只对「必审对象」输出待确认问题。
- 发现清单外仍有关键业务对象时：先回到 Skill0 补清单并经用户确认，再继续 Skill1。
- 不要把「可跳过对象」重新展开成决策题，除非用户在 Skill1 阶段主动要求加入。
- 审核与表述需区分：学生端看见什么 vs 教研后台配置什么；本页以学生端展示与交互规则为主，并标明对应配置来源。
