## 必审对象
1. 考点清单页签 — 文案/分页标识 — 页内居中「考点清单」（多考点）/「考点」（单考点） — 固定文案？单/多文案是否要分
2. 本页引导文案 — 文案 — 页签右侧提示 — 是否固定；是否仍暗示左右滑
3. 考点列表区域 — 区域 — 多考点时考点卡片列表 — 条数、顺序、空态（0 条考点）
4. 考点序号徽章 — 文案/标识 — 卡片上沿「考点1 / 考点2…」 — 编号规则与后台名称是否解耦
5. 考点名称 — 文案 — 考点卡片标题 — 配置来源、展示清洗规则
6. 考点展开/收起 — 操作 — 多考点点击标题展开一例题区 — 同时几个展开、再点是否收起、默认态
7. 考点说明 — 文案/区域 — 展开后「考点说明：」段落 — 未配置是否隐藏；富文本边界
8. 「典型例题」标签 — 文案/标识 — 例题区左上角 — 是否固定文案
9. 例题题干 — 文案 — 「典型例题」下方题干 — 配置边界、空态、富文本
10. 查看/收起解析 — 按钮 — 例题区「解析」开关 — 默认收起/展开、切换态
11. 解题步骤 — 区域 — 解析展开后的分步内容 — 条数、高亮段、空态
12. 解题要点 — 区域 — 步骤下方「解题要点」列表 — 0 条是否整块隐藏
13. 加入/移出好题本 — 按钮 — 例题标签内星标 + 解析底栏按钮 — 双入口是否同一状态；反馈文案
14. 好题本操作反馈 — 状态反馈 — 加入/移除后的 toast — 文案与是否必须本期定
15. 考点类型 — 类型标识 — 考点名称后的类型标签 — 后台配置、取值范围、缺省/非法值、是否可筛

## 可跳过对象
1. 单考点形态 — 仅演示对照，非正式产品主形态
2. 知识点名称与印章 — 已在核心概念页审过
3. 底部分页回到核心概念 — 切换方式已在核心概念页审过
4. 顶栏演示多/单考点开关 — 非正式学生能力
5. 返回 / 笔记 / 去测试 — 既往迭代或本期不挂审

## 供 Skill1 使用的约束
- 只对「必审对象」输出待确认问题。
- 发现清单外仍有关键业务对象时：先回到 Skill0 补清单并经用户确认，再继续 Skill1。
- 不要把「可跳过对象」重新展开成决策题，除非用户在 Skill1 阶段主动要求加入。
- 审核与表述需区分：学生端看见什么 vs 教研后台配置什么；本页以学生端展示与交互规则为主，并标明对应配置来源。
- 正式产品口径以多考点为主；单考点仅作演示对照，不单独展开决策题。
