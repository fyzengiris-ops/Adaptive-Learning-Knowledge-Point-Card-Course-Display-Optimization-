### SECTION_COURSE-002 三类来源 Tab

来源：代码事实 + 确认决策

#### 显示说明
1.1 同步课左侧展示三类来源：平台精选课、任课教师备课资料、课堂录像。
1.2 同一时间仅一个来源处于选中态，并展示该来源课程列表。

#### 数据来源
1.1 平台精选课来自平台配置的同步课。
1.2 任课教师备课资料来自本班教师为该小节准备的资料。
1.3 课堂录像来自该小节课堂实录。

#### 操作说明
1.1 点击来源 Tab 切换左侧课程列表；右侧练习试卷不随来源切换而变化。

#### 验收标准
1. 三个来源可切换且互斥选中。
2. 切来源时右侧试卷列表不变。

### SECTION_COURSE-003 来源数量角标

来源：确认决策

#### 显示说明
1.1 每个来源 Tab 旁展示数量角标。
1.2 无筛选时等于该来源全部课程数；有筛选时等于筛选后可见课程数。
1.3 可见数量为 0 时 Tab 仍显示，角标为 0。

#### 统计口径
1.1 只统计当前来源下的课程，不统计试卷。
1.2 仅课程状态筛选影响该角标；试卷筛选不影响。

#### 验收标准
1. 筛选前后数量角标随可见课程变化。
2. 为 0 时 Tab 仍在且显示 0。

### SECTION_COURSE-004 备课资料文件类型区分

来源：代码事实 + 确认决策

#### 显示说明
1.1 角标落在「任课教师备课资料」Tab；切到该来源后，列表内按文件类型分子类展示，至少区分视频与 PPT。
1.2 视频展示视频类型标识；PPT 展示 PPT 类型标识及页数。

#### 验收标准
1. 备课资料列表可区分视频与 PPT 类型。

### SECTION_COURSE-012 来源辅助说明文案

来源：代码事实

#### 显示说明
1.1 每个来源 Tab 下，资源列表上方展示一条辅助说明文案，随当前来源切换而变化。
1.2 平台精选课：「平台精选的同步学习课程，建议优先学习以掌握本小节核心知识点。」
1.3 任课教师备课资料：「本班任课教师为该小节准备的课件资料，可结合课堂进度查看，巩固当堂所学。」
1.4 课堂录像：「当前小节的课堂录像，建议课后复习学习；回看老师讲解，便于查漏补缺。」

#### 验收标准
1. 切到来源时可见对应该来源的辅助说明文案。

### SECTION_COURSE-005 课程学习状态

来源：代码事实 + 确认决策

#### 状态规则
1.1 课程状态保留三态：待学习、学习中、已学习。
1.2 三态在课程卡片上展示，并作为课程筛选项的一一映射。

#### 异常情况处理
1.1 当前来源下无课程时，课程区域显示「当前类型暂无资源，可查看其他类型的资源」。

#### 验收标准
1. 卡片可见三态之一。
2. 无课程时展示指定空状态文案。

### SECTION_COURSE-006 练习试卷区

来源：代码事实 + 确认决策

#### 显示说明
1.1 同步课右侧常显练习试卷区，含标题、辅助说明、套数、试卷列表（名称、题量/用时或得分、练习状态）。

#### 数据规则
1.1 练习试卷只挂在「当前小节 + 同步课」下，不按左侧来源拆分。
1.2 切换来源 Tab 时，试卷列表保持不变。
1.3 试卷来源通过配置后台获取；后续配置后台在为小节配置视频时，会支持配置配套的练习试卷。
1.4 本期先做好对接接口的设计即可。

#### 异常情况处理
1.1 未配置试卷时显示「暂未配置试卷」。

#### 验收标准
1. 切来源时试卷列表不变。
2. 无试卷时显示「暂未配置试卷」。
3. 试卷数据来源按配置后台对接口径设计。

#### 验收标准

#### 验收标准

### SECTION_COURSE-007 试卷套数

来源：代码事实 + 确认决策

#### 显示说明
1.1 练习试卷区展示当前小节同步课下的试卷套数，如「3 套」。

#### 统计口径
1.1 套数统计当前小节 + 同步课下的练习试卷总数。
1.2 不随左侧来源 Tab 切换而改变。
1.3 试卷状态筛选后，需展示筛选后的可见套数；无筛选时为全部套数。

#### 验收标准
1. 套数展示在试卷区标题旁。
2. 切换来源 Tab 时套数不变化。
3. 有试卷筛选时套数等于筛选后可见试卷数。

### SECTION_COURSE-014 试卷操作按钮

来源：代码事实 + 确认决策

#### 显示说明
1.1 每条试卷右侧展示操作入口，文案随练习状态变化。
1.2 未练习显示「去练习」；已练习显示「查看详情」。

#### 操作说明
1.1 点击「去练习」进入该试卷练习流程。
1.2 点击「查看详情」查看已练习试卷的结果/详情。

#### 验收标准
1. 未练习试卷展示「去练习」。
2. 已练习试卷展示「查看详情」。

### SECTION_COURSE-009 筛选维度

来源：代码事实 + 确认决策

#### 显示说明
1.1 页头提供筛选入口，点击打开筛选抽屉。
1.2 抽屉内展示两个筛选维度：课程状态、试卷状态。

#### 操作说明
1.1 点击确定应用筛选并关闭抽屉。
1.2 取消、点遮罩或点关闭只关闭抽屉，不改变已生效筛选。
1.3 提供「清除筛选」，点击后恢复未筛选状态。

#### 验收标准
1. 抽屉可见课程状态与试卷状态两个维度。
2. 取消不清除已生效筛选；清除筛选可恢复全部。

### SECTION_COURSE-010 课程筛选

来源：确认决策

#### 显示说明
1.1 课程筛选维度选项为：待学习、学习中、已学习（三选一）。

#### 操作说明
1.1 课程筛选只过滤左侧课程列表，不影响试卷列表。
1.2 可与试卷筛选同时生效。

#### 异常情况处理
1.1 课程侧筛选后无匹配时，课程区域显示「当前筛选状态暂无课程，可调整筛选项」。

#### 验收标准
1. 课程三态可筛选且只作用于课程。
2. 无匹配时课程区显示「当前筛选状态暂无课程，可调整筛选项」。

### SECTION_COURSE-011 试卷筛选

来源：确认决策

#### 显示说明
1.1 试卷筛选维度选项为：已练习、待练习（二选一）。

#### 操作说明
1.1 试卷筛选只过滤右侧试卷列表，不影响课程列表。
1.2 可与课程筛选同时生效。

#### 异常情况处理
1.1 试卷侧筛选后无匹配时，试卷区域显示「当前筛选状态暂无练习试卷，可调整筛选项」。

#### 验收标准
1. 试卷二态可筛选且只作用于试卷。
2. 无匹配时试卷区显示「当前筛选状态暂无练习试卷，可调整筛选项」。
