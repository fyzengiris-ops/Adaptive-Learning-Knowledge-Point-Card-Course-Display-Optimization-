#### 验收标准

2. 无课程配置时出现指定空状态文案。

### CHAPTER_COURSE-006 课程学习状态

来源：代码事实 + 确认决策

#### 显示说明

#### 验收标准

1. 切课型后试卷列表只含该课型试卷。

### CHAPTER_COURSE-015 练习试卷流转说明

来源：确认决策

#### 结果与流转

### CHAPTER_COURSE-013 筛选维度与入口

### CHAPTER_COURSE-014 学习状态筛选规则

来源：确认决策

#### 选取规则
1.1 筛选抽屉「学习状态」字段同时承载课程状态与试卷状态两组选项。
1.2 课程状态为三选一：待学习 / 学习中 / 已学习；仅过滤左侧课程列表，不影响试卷列表。
1.3 试卷状态为三选一：未练习 / 练习中 / 已练习；仅过滤右侧试卷列表，不影响课程列表。
1.4 两组条件可同时生效：课程条件只滤课程，试卷条件只滤试卷。

#### 显示说明
1.1 课程筛选项文案：待学习、学习中、已学习。
1.2 试卷筛选项文案：未练习、练习中、已练习。

#### 验收标准
1. 学习状态字段后可见本需求角标。
2. 选择某一课程状态后，仅课程列表按该状态过滤。
3. 选择某一试卷状态后，仅试卷列表按该状态过滤。

### CHAPTER_COURSE-016 筛选确定、取消与清除

来源：代码事实 + 确认决策

#### 操作说明
1.1 点「确定」立即按当前两组条件过滤并关闭抽屉。
1.2 点「取消」、关闭按钮或遮罩只关闭抽屉，不改变已生效筛选。
1.3 需提供「清除筛选」才能恢复为未筛选状态。

#### 异常情况处理
1.1 确定后若课程区无匹配，课程区显示「当前筛选状态暂无课程，可调整筛选项」。
1.2 确定后若试卷区无匹配，试卷区显示「当前筛选状态暂无试卷，可调整筛选项」。

#### 验收标准
1. 确定后筛选生效并关闭抽屉。
2. 取消不改变已生效筛选。
3. 分区无匹配时出现对应筛选空文案。
4. 存在清除筛选入口并可恢复未筛选。
