### 1.2 上级页面/上游入口
- 上级页面：专项学习中心（`#special`）或知识点学习入口
- 入口位置：点击知识点学习进入精讲卡
- 进入方式：hash 跳转至 `#kp-lecture`（默认第 1 页·核心概念）
- 传入数据：当前知识点 ID/配置（由后台下发；原型为本地数据集）
- 依赖状态：知识点精讲或视频至少一侧有可学内容（详见视频 Tab 规则）

### 1.3 下级页面/下游流程
- 下级页面/下游流程：同卡第 2 页「考点清单」；知识点视频 Tab（有配置时）；笔记/去测试为壳层入口
- 触发方式：底部分页圆点/箭头进入考点清单；顶栏 Tab 切换视频
- 传出数据：当前知识点上下文
- 后续状态：分页与演示模式为页内状态
- 返回逻辑：顶栏返回专项学习中心

### 1.4 范围边界摘要
- 本文档覆盖：知识点精讲卡片第 1 页（核心概念）：知识点名称、学业要求/考察频率、页签与引导、要点与配图、公式定理、底部分页切换；含壳层演示开关、视频 Tab 等。返回/页脚笔记/去测试本期不挂角标。考点清单页不在本期。
- 本文档不覆盖：返回、查看笔记、去测试、考点清单页及例题/解析/好题本

## 3. 业务逻辑说明

### KP_LECTURE_CONCEPT-001 知识点名称

来源：代码事实

#### 显示说明
1.1 卡片顶部展示当前知识点名称。
1.2 学生能进入本页时，知识点名称一定存在并展示，不出现缺省占位。

#### 数据来源
1.1 知识点名称由教研老师在配置后台配置，随当前知识点下发到学生端。

#### 验收标准
1. 进入精讲页可见知识点名称。
2. 名称与当前进入的知识点一致。

### KP_LECTURE_CONCEPT-002 学业要求

来源：代码事实 + 确认决策

#### 显示说明
1.1 知识点名称旁以印章形式展示学业要求短文案。
1.2 该字段非必配；未配置时不展示印章。

#### 数据规则
1.1 学业要求为封闭枚举：了解 / 理解 / 掌握 / 运用（可按现网微调，但仍为封闭枚举）。
1.2 具体展示标签由配置后台下发，学生端按后台返回值展示。

#### 验收标准
1. 已配置学业要求时，标题旁可见对应印章文案。
2. 未配置学业要求时，不展示该印章。
3. 展示文案与后台为该知识点配置的学业要求一致。

### KP_LECTURE_CONCEPT-003 考察频率

来源：代码事实 + 确认决策

#### 显示说明
1.1 知识点名称旁以印章形式展示考察频率短文案。
1.2 该字段非必配；未配置时不展示印章。

#### 数据规则
1.1 考察频率为封闭枚举：高频 / 中频 / 低频。
1.2 具体展示标签由配置后台下发，学生端按后台返回值展示。

#### 验收标准
1. 已配置考察频率时，标题旁可见对应印章文案。
2. 未配置考察频率时，不展示该印章。
3. 展示文案与后台为该知识点配置的考察频率一致。

### KP_LECTURE_CONCEPT-004 核心概念页签

来源：代码事实 + 确认决策

#### 显示说明
1.1 核心概念页居中展示页签文案「核心概念」。
1.2 该文案为产品固定文案，后台不可配，学生端不可改。

#### 异常情况处理
1.1 【8.11需求评审后补充】核心概念模块，什么信息都没有的情况（即既无要点，也无公式定理的时候），展示缺省图和提示文案。

#### 验收标准
1. 核心概念页可见固定文案「核心概念」。
2. 既无要点也无公式定理时，展示缺省图与提示文案。

### KP_LECTURE_CONCEPT-005 进入考点页的引导文案

来源：代码事实

#### 显示说明
1.1 核心概念页在页签附近展示固定引导文案，提示学生可进入考点清单页。
1.2 引导文案为固定展示信息，后台不可配。
1.3 引导口径与正式切换方式一致：引导使用底部分页圆点或底栏箭头，不引导手势左右滑。

#### 验收标准
1. 核心概念页可见固定引导文案。
2. 引导不暗示支持手势左右滑切换。

### KP_LECTURE_CONCEPT-006 要点模块

来源：代码事实 + 确认决策

#### 显示说明
1.1 有要点时，以带「要点」标识的单容器展示多条编号要点，编号按后台配置顺序从 1 起排。
1.2 允许配置 0 条要点；无要点时整块「要点」模块不渲染，不展示空容器。

#### 数据来源
1.1 要点列表由教研在配置后台配置后下发。

#### 展示顺序
1.1 学生端按后台配置的要点顺序展示，不在学生端重排。

#### 验收标准
1. 有要点时可见带编号的要点容器。
2. 无要点时页面不出现空的要点容器。

### KP_LECTURE_CONCEPT-007 单条要点正文

来源：代码事实 + 确认决策

#### 显示说明
1.1 每条要点展示后台配置的正文内容，支持较长文案换行阅读。
1.2 本页不提供富文本编辑能力。
1.3 学生端按乐课网现有富文本编辑能力所能产出的效果做渲染展示。

#### 数据边界
1.1 正文内容在配置后台完成编辑；学生端只负责按乐课网富文本能力集渲染，不在本页二次编辑。

#### 验收标准
1. 要点正文按后台配置展示。
2. 乐课网富文本能力范围内的效果可在学生端正确呈现。
3. 学生端本页无编辑入口。

### KP_LECTURE_CONCEPT-008 要点配图

来源：代码事实 + 确认决策

#### 显示说明
1.1 配图挂在单条要点下展示。
1.2 允许单条要点配置并展示多张图片。
1.3 多图呈现效果与后台配置一致：可按配置换行多图，也可单行展示多张图片。
1.4 该条要点无图时不占位。
1.5 【8.11需求评审后补充】当只有一张图片的时候，整张图片满屏显示；当有两张图片的时候或者是图片数量为双数的时候，每两张图片在同行等比例显示；若是三张及以上的奇数图片张数，同理，每两张图片同行等比例显示，最后一张奇数图片换行居中显示。

#### 操作说明
1.1 学生可点击图片进入放大预览。
1.2 在预览层点击关闭或点击遮罩可退出预览，回到核心概念页原位置。

#### 数据来源
1.1 图片及多图排布由教研在配置后台配置，学生端按配置结果展示。

#### 验收标准
1. 有多图配置的要点可按后台排布展示多张图。
2. 无图要点不出现空白图位。
3. 点击图片可放大，关闭后回到原页。
4. 1 张图满宽展示；偶数张每行 2 张等比例；奇数张（≥3）前序每行 2 张，末张换行居中。

### KP_LECTURE_CONCEPT-009 公式定理模块

来源：代码事实 + 确认决策

#### 显示说明
1.1 未配置任何公式时，整块「公式定理」模块不展示。
1.2 已配置时按后台顺序全部展示。
1.3 模块左上角展示标签：仅 1 条时为「公式定理」；多条时为「公式定理 · N 条」（N 为当前公式条数）。
1.4 每条按「名称：内容」单行呈现；名称为空时只展示内容。

#### 数据来源
1.1 公式定理列表由教研在配置后台配置后下发。

#### 验收标准
1. 无公式配置时页面不出现公式定理空模块。
2. 有多条公式时全部按顺序展示，且为「名称：内容」单行形态。
3. 多条时左上角标签可见「公式定理 · N 条」。

### KP_LECTURE_CONCEPT-010 切换到考点清单

来源：代码事实 + 确认决策

#### 操作说明
1.1 学生可通过底部分页圆点，或底栏左右箭头，从核心概念页切换到考点清单页。
1.2 从考点清单页可通过同样方式返回核心概念页。
1.3 不支持手势左右滑切换，避免与页内纵向滚动冲突。

#### 显示说明
1.1 底部分页指示当前处于核心概念页或考点页。
1.2 在核心概念页时，「上一页」不可用；切到考点页后「下一页」不可用。

#### 验收标准
1. 点击分页圆点或箭头可进入考点清单页。
2. 手势左右滑不会切换页面。

### KP_LECTURE_CONCEPT-011 演示多考点/单考点开关

来源：代码事实

#### 显示说明
1.1 顶栏右侧展示「多考点 / 单考点」演示开关，用于原型评审对照两种形态。

#### 数据边界
1.1 该开关仅为评审演示，不属于学生正式产品能力；正式环境不向学生提供此切换。

#### 验收标准
1. 原型顶栏可见演示开关。
2. 需求说明中明确其为演示用途、非正式学生能力。

### KP_LECTURE_CONCEPT-012 知识点视频 Tab

来源：代码事实 + 确认决策

#### 显示说明
1.1 顶栏在「知识点精讲」旁提供「知识点视频」Tab。
1.2 配置后台已配置该知识点的视频信息时，展示「知识点视频」Tab；未配置视频信息时，不展示该 Tab。
1.3 仅配置了视频、未配置知识点精讲时，「知识点精讲」Tab/模块暂不展示，仅展示视频相关内容。
1.4 有精讲内容可进入本页时，默认落在「知识点精讲」Tab。

#### 异常边界
1.1 当视频与知识点精讲均未配置时，用户点击「知识点学习」不进入精讲页，弹窗提示：「正在更新中，先去学习其他知识点吧~」。

#### 验收标准
1. 未配置视频时，顶栏不出现「知识点视频」Tab。
2. 仅有视频、无精讲时，不展示「知识点精讲」Tab/模块。
3. 已配置视频且有精讲时，可见「知识点视频」Tab，且默认仍落在知识点精讲。
4. 精讲与视频皆未配置时，点击知识点学习弹出「正在更新中，先去学习其他知识点吧~」，且不进入精讲页。
